# Generalized Attribute Relationship System

## Overview

This document captures a design approach for creating reusable mathematical relationships between character attributes.  

The goal is the same economy of scale we achieved with the **-genic / -lytic** pattern:

- The game engine understands a small set of core relationship types.
- Game designers define specific attributes and wire them into those relationships.
- The same underlying rules can power many different gameplay systems with different “skins.”

This creates variety for players while keeping the underlying systems consistent and maintainable.

---

## Core Relationship Patterns

| Relationship Type                  | Description | Mathematical Shape | Classic Examples |
|------------------------------------|-------------|--------------------|------------------|
| **Resource + Protector**           | One attribute absorbs or reduces loss to another. | Incoming effect is reduced by Protector before applying to Resource | Health + Armor<br>Health + Resistance<br>Health + Shield |
| **Resource + Regenerator**         | One attribute restores another over time or on trigger. | Resource += Regenerator × time (or on event) | Health + Regeneration<br>Mana + Mana Regen<br>Stamina + Recovery |
| **Opposed / Competing (Contested)**| Two attributes from different entities work against each other. | Final value = AttackerStat − DefenderStat<br>or ratio-based | Accuracy vs Dodge<br>Stealth vs Perception<br>Penetration vs Armor |
| **Stat + Enhancer**                | One attribute multiplies or adds to another’s effectiveness. | EffectiveStat = BaseStat × (1 + Enhancer)<br>or BaseStat + Enhancer | Strength + Damage%<br>Speed + Movement Bonus<br>Luck + Critical Chance |
| **Stat + Enabler / Threshold**     | One attribute determines whether another can be used or how strongly. | If Stat ≥ Threshold → allow or scale the other | Strength → Carry Capacity<br>Intelligence → Max Mana<br>Agility → Max Dodge |
| **Resource + Consumer**            | Using one attribute spends another. | On action: ResourceA is spent to affect ResourceB or Stat | Stamina spent to Sprint (boost Speed)<br>Mana spent for Aimed Shot (boost Accuracy) |
| **Producer + Resource**            | One attribute generates another over time or on action. | Resource += Producer × time | Constitution → Health Regen<br>Intelligence → Mana Regen |
| **Amplifier Pair**                 | Two attributes multiply each other’s effect. | Final Effect = AttrA × AttrB | Strength × Weapon Skill → Melee Damage<br>Intelligence × Spell Power → Magic Damage |
| **Diminishing / Soft Cap**         | Higher values of one attribute give decreasing returns. | Bonus = Attr / (Attr + Constant) | High Armor → diminishing damage reduction<br>High Accuracy → approaches but never reaches 100% |

## Naming the Key Patterns

| Pattern                        | Recommended Name          | Alternative Names                  |
|--------------------------------|---------------------------|------------------------------------|
| Health + Armor style           | **Resource + Protector**  | Attribute + Protector             |
| Accuracy vs Dodge style        | **Opposed Pair**          | Contested Pair, Challenger / Resistor |
| Strength boosting Damage       | **Stat + Enhancer**       | Attribute + Enhancer              |
| Full survival loop             | **Survival Triplet**      | Resource + Protector + Regenerator |

## Suggested Engine-Level Relationship Types

The engine can hard-support a small set of relationship verbs. Designers then declare specific instances.

**Core Relationship Verbs:**
- `Protects`          → A protects B  
- `Regenerates`       → A regenerates B  
- `Opposes`           → A opposes B (usually across two entities)  
- `Enhances`          → A enhances B  
- `Enables`           → A enables or gates B  
- `Consumes`          → Using A costs B  
- `Produces`          → A generates B  
- `Amplifies`         → A multiplies B  

**Example Declarations:**
```text
Health        is protected by     Armor
Health        is regenerated by   Regeneration
Accuracy      opposes             Dodge
Strength      enhances            Melee Damage
Stamina       is consumed by      Sprint
Constitution  produces            Health Regeneration
