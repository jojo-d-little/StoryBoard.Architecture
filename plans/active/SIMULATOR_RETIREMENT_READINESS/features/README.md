# Feature Packets And Pass Handoffs

The roadmap is the dispatch index. Each feature folder contains its feature packet and the pass handoffs instantiated when a pass is scheduled.

1. Area profiles define ownership, allowlists, compatibility, and validation expectations.
2. A feature packet defines feature completion and the ordered area-pass matrix.
3. A pass handoff is the only document an implementation session executes and updates.
4. Do not pre-create speculative remediation handoffs; create them when an integration pass assigns a concrete owner gap.
