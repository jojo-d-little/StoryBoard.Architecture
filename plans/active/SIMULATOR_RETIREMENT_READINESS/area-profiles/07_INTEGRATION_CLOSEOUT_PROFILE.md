# Integration / Closeout Area Profile

Purpose: boundary profile for evidence-only vertical integration, feature closure, final readiness decision, and post-Go launch cutover records.

## Boundary Rules

1. Integration passes are no-code by default; they identify and assign gaps to the owning feature-area pass.
2. Narrow test stabilization requires explicit approval and must not become cross-area product implementation.
3. F07 owns readiness Go/No-Go. F08 records the post-Go Designer launch cutover; neither authorizes WPF application/code deletion.

## Required Pass Evidence

1. End-to-end scenario results and exact owner assignment for every failure.
2. Feature closure reconciliation across pass handoffs and parity rows.
3. Final Go/No-Go rationale, waivers, and follow-on scope where applicable.
