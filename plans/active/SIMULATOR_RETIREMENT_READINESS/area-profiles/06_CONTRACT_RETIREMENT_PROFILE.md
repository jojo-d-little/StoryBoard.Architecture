# Contract Retirement Area Profile

Purpose: globally gated profile for intentional non-backward-compatible contract retirement.

## Status

Skipped for simulator-retirement readiness unless an explicit approved retirement list reopens it.

## Entry Criteria

1. All affected consumers have migrated.
2. The retirement list and downstream impact are approved.
3. Compatibility/code-generation validation is planned.

## Boundary Rules

1. Actual WPF application/code deletion is not contract retirement work.
2. No pass may use this profile merely to simplify an additive consumer implementation.
