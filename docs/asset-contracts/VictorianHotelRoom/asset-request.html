Asset Request: Victorian Hotel Room Package

Status: Open Theme: Victorian Hotel Room

1) Purpose and Scope

Goal

Request is for a complete room-image asset package for a Victorian Hotel room that can be assembled by runtime layering.

Assets should be designed to support a variety of room layouts and door placements, while maintaining a consistent visual theme.

  • Room image size: 800x600
  • Long wall span: 800 px
  • Short wall span: 600 px
  • Assets should allow for both open and closed door states
  • Two door styles are requested: a larger ornate door for room entry/exit and a smaller door for use as an interior closet or bathroom door.

Victorian style leaves a lot of room for interpretation, so the artist is encouraged to explore elements such as:
  • Ornate woodwork
  • Patterned wallpaper
  • Rugs over wooden floors
  • Bay windows
  • Decorative trim

Any rugs or floor coverings should be designed to be removable, so that the base floor can be seen in some room layouts....i.e. a separate image.

One wall design needs to include a window. A bay window would be ideal and a good opportunity to show using a "thicker" wall to provide additional detail.

Out of Scope (for now)

This request does not include any furniture, lighting, or other room objects. Those will be requested in a future asset package.

5) Technical Baseline

File Format

  • Primary export format: PNG
  • Optional source format: layered PSD/XCF
  • Folder structure and naming conventions: VicHotel_X where X is descriptive of what it is (e.g., Floor, LongWall, ShortWall, Door_Open, Door_Closed, Door_Small).

Fixed Dimensions

  • Room canvas: 800x600 (floor image is exactly 800px-600px)
  • Long wall span target: 800 px
  • Short wall span target: 600 px
  • Open/closed door variants must share exact outer dimensions

Transparency Rules

  • Door-opening walls include intentional transparent cutout.
  • Door art should visually hide cutout seams.
  • Decorative items such as rugs, corner details, etc. use transparency to overlay the base floor or walls.

Flexible Areas

  • Wall thickness/detail depth may vary.
  • Corner decorators are optional.
